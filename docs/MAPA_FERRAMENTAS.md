# Mapa de ferramentas do Celsius

Guia simples do que o assistente Celsius pode fazer. Organizado por area de
trabalho, com exemplos do que digitar no chat.

> **Como funciona:** tudo que o Celsius faz abaixo roda **no seu computador**.
> Seus dados (clientes, estoque, documentos, memorias) ficam locais e so saem da
> maquina em operacoes que voce pediu explicitamente na internet (pesquisar,
> noticias). Nada e enviado para servidores de publicidade.

---

## 1. Conversa e memoria

| O que faz | Como pedir |
| --- | --- |
| Lembra de algo que voce disse | "lembre que o cliente Silva prefere pagamento a prazo" |
| Busca na memoria o que foi guardado | "o que eu disse sobre a obra do centro?" |
| Responde com contexto da conversa atual | "e se tivermos atraso, o que eu faço?" |

---

## 2. Documentos e base de conhecimento

| O que faz | Como pedir |
| --- | --- |
| Le arquivos (PDF, Word, Excel, ODT, texto) | "processe o arquivo orcamento_fabrica.pdf" |
| Mostra o conteudo de um arquivo | "abrir o arquivo contato_clientes.txt" |
| Cria, edita e salva arquivos com sua autorizacao | "crie um arquivo nota_reuniao.md com as decisoes" |
| Identifica campos de formularios Word e PDF | "inspecione os campos deste formulario" |
| Preenche uma copia de um DOCX sem alterar o modelo | "preencha este PAEE com os dados que vou informar" |
| Copia dados confirmados de outros documentos para um modelo | "use a ficha e o laudo anexados para completar este formulario" |
| Preenche campos interativos de PDF (AcroForm) | "preencha os campos deste PDF e me entregue uma copia" |
| Adiciona um documento a base de conhecimento | "indexe o manual_garantia.pdf" |
| Consulta a base de conhecimento nas respostas | "qual a garantia de cada produto? use os manuais" |
| Mostra documentos ja indexados | "quais documentos estao indexados?" |
| Remove documento da base | "remova o arquivo contrato_antigo.pdf" |
| Lista arquivos de uma pasta | "liste os arquivos da pasta Propostas" |

> **Privacidade:** escrever ou editar arquivos sempre pede um codigo de
> autorizacao exibido na tela. O Celsius so mexe nas pastas que voce liberou.
> O arquivo original nunca e sobrescrito. PDFs estaticos ou digitalizados nao
> possuem campos editaveis; nesses casos, use o DOCX de origem ou um modelo de
> coordenadas previamente revisado.

## 3. Internet e pesquisa

| O que faz | Como pedir |
| --- | --- |
| Pesquisa na web em geral | "pesquise a cotacao do dolar hoje" |
| Pesquisa no Google | "pesquise no google fornecedores de aco em SP" |
| Busca noticias recentes | "quais as ultimas noticias sobre energia solar?" |
| Acessa um site e resume o conteudo | "acesse a pagina e extraia as especificacoes" |
| Abre um site no navegador | "abra o site da prefeitura" |

> **Privacidade:** estas sao as unicas ferramentas que usam internet — e apenas
> quando voce pedir.

## Painel web e celular

O Celsius tambem acompanha a tarefa em outros canais:

- **Aplicativo de mesa (desktop)** — o chat completo com todas as ferramentas acima.
- **Painel web** — cadastros, estoque, agenda, relatorios, documentos e graficos.
- **Acesso pelo celular (aplicativo companheiro)** — voz, lembretes e consulta
  rapida usando os mesmos dados do seu computador.

---

## Resumo em uma frase

> O Celsius e um assistente que **conversa, lembra, pesquisa e trabalha com seus
> documentos, clientes, estoque, agenda e relatorios** — tudo local, seguro e com
> sua autorizacao nas acoes importantes.
